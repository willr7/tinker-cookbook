## Problem Understanding

1. Takahashi has N days of summer vacation
2. He has M assignments, where the i-th assignment takes A_i days to complete
3. He can only work on one assignment per day
4. He cannot hang out on days when he's doing assignments
5. We need to find the maximum number of days he can hang out if he finishes all assignments

## Key Insights

1. The total time needed to complete all assignments is the sum of all A_i days
2. If the total assignment time exceeds N days, he cannot finish all assignments → return -1
3. If he can finish all assignments, the maximum hangout days = N - (sum of all assignment days)

## Step-by-step Solution

1. Read N (vacation days) and M (number of assignments)
2. Read the array A of assignment durations
3. Calculate the total days needed for all assignments: sum(A)
4. If sum(A) > N, return -1 (can't finish all assignments)
5. Otherwise, the hangout days = N - sum(A)

- Assignments: [5, 6]

- Since 11 ≤ 41, he can finish all assignments
- Hangout days = 41 - 11 = 30 ✓

## Edge Cases

- If N is very small compared to total assignment time → return -1
- If all assignments take 1 day each → hangout days = N - M
