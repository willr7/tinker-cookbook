## Problem Understanding

1. Takahashi has N days of summer vacation
2. He has M assignments, where the i-th assignment takes A_i days to complete
3. He can only work on one assignment per day
4. He cannot hang out on days when he's working on assignments
5. We need to find the maximum number of days he can hang out after completing all assignments
6. If he can't finish all assignments within N days, return -1

## Key Insights

1. The total time needed to complete all assignments is the sum of all A_i days
2. If the sum of all assignment days exceeds N, then it's impossible to complete all assignments, so return -1
3. If the sum is less than or equal to N, then the remaining days (N - sum of all A_i) are the maximum days he can hang out

## Step-by-step Solution

1. Read N (total vacation days) and M (number of assignments)
2. Read the array A of assignment durations
3. Calculate the total days needed for all assignments: sum(A)
4. Check if sum(A) > N:
   - If yes, return -1 (impossible to complete all assignments)
5. If sum(A) ≤ N, return N - sum(A) (remaining days for hanging out)

## Verification with Sample

- N = 41, M = 2
- A = [5, 6]
- Sum of assignments = 5 + 6 = 11
- 11 ≤ 41, so possible
- Days for hanging out = 41 - 11 = 30
- Output: 30 ✓

## Edge Cases

- If N = 0, then no vacation days available
- If any assignment takes more than N days, it's impossible
- But since we sum all assignments and check against N, we handle this implicitly
