The key insight is that during the merge process of merge sort, whenever we take an element from the right subarray (which has smaller values), it means all remaining elements in the left subarray form inversions with this element.

**Steps:**

3. During merge, count inversions between left and right halves
4. Return total inversions

## Detailed Algorithm

When merging two sorted arrays (left and right):
- For each element in the right array, if it's smaller than some elements in the left array, those form inversions
- Specifically, if we take an element from the right array at position j, then all remaining elements in the left array (from current position to end) will form inversions with this element
- So when we take an element from the right array, we add the number of remaining elements in the left array to the inversion count

We need an O(n log n) solution. The best approach is to use **Merge Sort** with inversion counting.

In merge sort, when we merge two sorted halves, if an element from the right half is smaller than an element from the left half, then all remaining elements in the left half are also greater than this element, creating inversions.

## Algorithm Steps

1. Use modified merge sort that counts inversions during the merge process
2. During the merge step, when we take an element from the right half, it forms inversions with all remaining elements in the left half
3. The total inversions = inversions in left half + inversions in right half + inversions formed during merge

3. Divide array into two halves
4. Recursively count inversions in each half

6. Return total inversions

def merge_and_count(arr, temp, left, right):
    if left >= right:
        return 0
    
    mid = (left + right) // 2
    inv_count = 0
    
    # Count inversions in left half
    inv_count += merge_and_count(arr, temp, left, mid)
    # Count inversions in right half
    inv_count += merge_and_count(arr, temp, mid + 1, right)
    
    # Count inversions during merge
    i, j, k = left, mid + 1, left
    while i <= mid and j <= right:
        if arr[i] <= arr[j]:
            temp[k] = arr[i]
            i += 1
        else:
            # arr[j] < arr[i], so all elements from i to mid are > arr[j]
            # This gives (mid - i + 1) inversions
            temp[k] = arr[j]
            inv_count += (mid - i + 1)
            j += 1
        k += 1

        i += 1

        j += 1
        k += 1
