- We want to minimize i + j - 2 (since moves = i + j - 2)

So we need to find a factorization N = i × j where i + j is minimized.

## Mathematical Analysis

For any factor pair (i,j) where i × j = N, we want to minimize i + j.

By the AM-GM inequality, for a fixed product, the sum i + j is minimized when i and j are as close as possible to √N.

So the optimal solution is when i and j are factors of N that are closest to √N.

## Algorithm

1. Find all divisors of N up to √N
2. For each divisor i (where i ≤ √N), j = N/i
3. Calculate the sum i + j for each valid pair
4. Return min(i + j) - 2 (since moves = i + j - 2)

## Optimization

We only need to check divisors up to √N because if i ≤ √N, then j = N/i ≥ √N, and we'll get the same pairs in reverse.

## Edge Cases

- When N is a perfect square, i = j = √N
- For large N (up to 10^12), we can iterate up to √N which is 10^6, which is acceptable
