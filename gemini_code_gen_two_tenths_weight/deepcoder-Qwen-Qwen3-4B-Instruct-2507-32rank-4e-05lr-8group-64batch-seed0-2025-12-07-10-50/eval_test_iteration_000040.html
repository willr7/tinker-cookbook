- "101" has '1','0','1' → has 1 before 0 and 1 after 0 → invalid

Any piece with a 1 followed by a 0 is invalid.

So we must separate every "1" that is immediately followed by a "0".

Therefore, the minimum number of pieces is 1 + (number of indices i where s[i] == '1' and s[i+1] == '0').

Let me verify with examples:

1. "010": 
   - i=1: s[1]='1', s[2]='0' → count = 1
   - pieces = 1 + 1 = 2 ✓

2. "101":
   - i=0: s[0]='1', s[1]='0' → count = 1
   - pieces = 1 + 1 = 2 ✓

3. "110":
   - i=1: s[1]='1', s[2]='0' → count = 1
   - pieces = 2 ✓

4. "1001":
   - i=0: '1','0' → count = 1
   - i=2: '0','1' → no
   - pieces = 2
   - Pieces: ["1"], ["001"] → "001" has 0s before 1s ✓ → can rearrange to "0011" ✓

Wait, "001" has all 0s before 1s → valid ✓

5. "0110":
   - i=1: '1','1' → no
   - i=2: '1','0' → count = 1
   - pieces = 2
   - Cut after position 2: ["011", "0"] → "011" has 0 before 1s ✓

But can we do it with 1 piece? "0110" → has '1' after '0' and '1' before '0' → invalid within piece.

So minimum is 2 ✓

Therefore, the algorithm is:
- Count the number of indices i (0 ≤ i < n-1) such that s[i] == '1' and s[i+1] == '0'
- Answer = 1 + count

```python
t = int(input())
for _ in range(t):
    s = input().strip()
    n = len(s)
    if n == 1:
        print(1)
    else:
        count = 0
        for i in range(n - 1):
            if s[i] == '1' and s[i + 1] == '0':
                count += 1
        print(1 + count)
```
