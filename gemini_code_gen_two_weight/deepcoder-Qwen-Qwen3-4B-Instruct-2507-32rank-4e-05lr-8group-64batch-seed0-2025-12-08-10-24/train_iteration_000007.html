## Problem Understanding

1. Takahashi has N days of vacation
2. He has M assignments, where the i-th assignment takes A_i days to complete
3. He can only work on one assignment per day
4. He cannot hang out on days when he's working on assignments
5. We need to find the maximum number of days he can hang out
6. If he can't finish all assignments within N days, return -1

## Analysis

The key insight is:
- Total days needed to complete all assignments = sum of all A_i
- If this sum exceeds N, then he can't finish all assignments → return -1
- Otherwise, the maximum hangout days = (total vacation days) - (total days spent on assignments)

## Step-by-step Solution

1. Read N (vacation days) and M (number of assignments)
2. Read the array A of assignment durations
3. Calculate the total days needed for all assignments
4. If total days > N, return -1
5. Otherwise, return (N - total_days_needed)

## Example Verification

Given: N=41, M=2, A=[5,6]
- Total assignment days = 5 + 6 = 11
- Since 11 ≤ 41, he can finish all assignments
- Maximum hangout days = 41 - 11 = 30 ✓

## Implementation

```python
# Read input
N, M = map(int, input().split())
A = list(map(int, input().split()))

# Calculate total days needed for all assignments
total_assignment_days = sum(A)

# Check if Takahashi can finish all assignments
if total_assignment_days > N:
    print(-1)
else:
    # Maximum hangout days = total vacation days - days spent on assignments
    hangout_days = N - total_assignment_days
    print(hangout_days)
```

The solution is straightforward:
- We don't need to worry about the order of assignments since we just need to know the total time spent
- As long as the sum of all assignment durations doesn't exceed N days, we can schedule all assignments and have the remaining days for hanging out
- If the sum exceeds N, it's impossible to complete all assignments, so we return -1
