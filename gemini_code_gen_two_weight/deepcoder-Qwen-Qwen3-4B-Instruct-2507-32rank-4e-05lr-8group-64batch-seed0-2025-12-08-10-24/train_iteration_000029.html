## Key Insight

The constraint "no cycle of length exactly 3" means the graph is triangle-free.

From graph theory, for a triangle-free graph with `n` vertices, the maximum number of edges is given by **Turán's theorem**. Specifically, the maximum number of edges in a triangle-free graph is achieved by the complete bipartite graph that is as balanced as possible between the two partitions.

For a complete bipartite graph `K_{a,b}` where `a + b = n`, the number of edges is `a × b`.

To maximize `a × b` given `a + b = n`, we need to make `a` and `b` as close as possible:
- If `n` is even: `a = b = n/2`, edges = `(n/2)² = n²/4`
- If `n` is odd: `a = (n-1)/2`, `b = (n+1)/2`, edges = `(n-1)/2 × (n+1)/2 = (n²-1)/4`

So the maximum number of edges is `floor(n²/4)`.

- Maximum edges = floor(3²/4) = floor(9/4) = 2

- Complete bipartite graph K_{2,2} has 2×2 = 4 edges ✓
