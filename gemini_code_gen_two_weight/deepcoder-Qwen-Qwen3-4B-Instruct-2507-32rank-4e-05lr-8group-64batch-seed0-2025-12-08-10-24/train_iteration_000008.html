## Key Insight

Since the cycles are independent, we can think about when each LED is ON:

- Red is ON in seconds: R, R+1, ..., 2R-1 (mod 2R)
- Green is ON in seconds: G, G+1, ..., 2G-1 (mod 2G)
- Blue is ON in seconds: B, B+1, ..., 2B-1 (mod 2B)

We can simulate the pattern in the least common multiple (LCM) of the cycle periods, but since T can be large, we need an efficient approach.
