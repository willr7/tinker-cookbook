## Problem Understanding

1. We have n students with names, and we need to split them into two classrooms
2. Two students are "chatty" if they have the same first letter AND are in the same classroom
3. We want to minimize the total number of chatty pairs
4. A chatty pair is counted only once (not both (a,b) and (b,a))

## Key Insights

1. Students with the same first letter form groups - we need to decide how to split each group between classrooms
2. For a group of k students with the same first letter, if we split them into classroom A with `a` students and classroom B with `b` students (where `a + b = k`), the number of chatty pairs is:
   - In classroom A: `a * (a-1) / 2` pairs
   - In classroom B: `b * (b-1) / 2` pairs
   - Total for this group: `a * (a-1) / 2 + b * (b-1) / 2`
   
3. Since we want to minimize the total chatty pairs, we should try to balance the distribution of students with the same first letter.

4. For a group of size k, the optimal split is:
   - If we split into `a` and `k-a`, we want to minimize `a*(a-1)/2 + (k-a)*(k-a-1)/2`
   - This function is minimized when `a` is as close to `k/2` as possible
   - The minimum occurs when `a = floor(k/2)` or `a = ceil(k/2)`

5. For each group of students with the same first letter, we calculate the minimum chatty pairs we can get from that group.

6. The total minimum chatty pairs is the sum of minimum chatty pairs from all groups.

## Step-by-step Solution

1. Group students by their first letter
2. For each group of size k:
   - If k = 1: 0 pairs (can't form pairs)
   - If k = 2: 1 pair (if both in same room) or 0 pairs (if split) → minimum is 0
   - If k > 2: split optimally to minimize pairs
3. Sum up the minimum pairs from all groups

For a group of size k, the optimal split is:
- Put `a = k // 2` students in one classroom and `b = k - a` in another
- Chatty pairs = `a*(a-1)/2 + b*(b-1)/2`

## Key Insights

1. Students with the same first letter form groups - within each group, if two or more students are in the same classroom, they form chatty pairs
2. For a group of size k with students having the same first letter:
   - If we split them into two classrooms, the chatty pairs formed will depend on how we distribute them
   - If we put `a` students in classroom 1 and `k-a` students in classroom 2:
     - Classroom 1 has `C(a,2) = a*(a-1)/2` chatty pairs
     - Classroom 2 has `C(k-a,2) = (k-a)*(k-a-1)/2` chatty pairs
     - Total = `a*(a-1)/2 + (k-a)*(k-a-1)/2`
3. We want to minimize the sum of chatty pairs across all groups

## Strategy

For each group of students with the same first letter:
- We need to find the optimal split between the two classrooms
- For a group of size k, we try all possible distributions (0 to k students in one classroom, rest in the other)
- We calculate the total chatty pairs for each distribution
- We take the minimum

1. Group students by their first letter
2. For each group, calculate the minimum chatty pairs possible when distributing students between classrooms
3. Sum up the minimum chatty pairs from all groups

def solve():
    n = int(input())
    names = []
    for _ in range(n):
        names.append(input().strip())
    
    # Group students by first letter
    groups = {}
    for name in names:
        first_letter = name[0]
        if first_letter not in groups:
            groups[first_letter] = 0
        groups[first_letter] += 1
    
    # Calculate minimum chatty pairs
    total_chatty_pairs = 0
    
    for group_size in groups.values():
        if group_size <= 1:
            # No chatty pairs possible (0 or 1 student)
            continue
            
        # For a group of size k, find the distribution that minimizes chatty pairs
        min_pairs = float('inf')
        
        # Try all possible distributions: put i students in classroom 1, (k-i) in classroom 2
        for i in range(group_size + 1):
            # Chatty pairs in classroom 1: C(i,2) = i*(i-1)/2
            # Chatty pairs in classroom 2: C(k-i,2) = (k-i)*(k-i-1)/2
            pairs = i * (i - 1) // 2 + (group_size - i) * (group_size - i - 1) // 2
            min_pairs = min(min_pairs, pairs)
        
        total_chatty_pairs += min_pairs
    
    return total_chatty_pairs
