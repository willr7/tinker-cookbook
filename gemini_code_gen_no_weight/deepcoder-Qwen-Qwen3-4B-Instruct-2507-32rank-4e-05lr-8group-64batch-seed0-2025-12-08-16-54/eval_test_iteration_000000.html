## Problem Understanding

1. We need to rearrange characters of string `s` to form a new string `r`
2. The new string `r` must NOT be equal to the original string `s`
3. If it's impossible to create such a string, output "NO"
4. Otherwise, output "YES" and the rearranged string

## Key Insights

1. **When is it impossible?** 
   - If the string has only one unique character (like "aaa", "bbb"), then any rearrangement will be the same as original
   - If the string has length 1, we can't create a different arrangement
   - If all characters are the same, any permutation will be identical

2. **When is it possible?**
   - If there are at least two different characters in the string
   - If the string has length ≥ 2

## Algorithm

1. Check if the string length is 1: if yes, impossible → "NO"
2. Check if all characters are the same: if yes, impossible → "NO"
3. Otherwise, we can rearrange to create a different string → "YES"
4. To create a different string, we can simply sort the characters (which gives us a valid rearrangement) or swap any two different characters

## Step-by-step Solution

1. For each test case:
   - Read string `s`
   - If length is 1 → "NO"
   - If all characters are same → "NO" 
   - Otherwise → "YES" + any valid rearrangement (like sorted version)

Let me trace through examples:
- "abc" → can rearrange to "acb", "bac", etc. → "YES" + "acb"
- "aaa" → all same → "NO"
- "ab" → can rearrange to "ba" → "YES" + "ba"
- "a" → length 1 → "NO"

```python
t = int(input())
for _ in range(t):
    s = input().strip()
    
    # If length is 1, impossible to create different string
    if len(s) == 1:
        print("NO")
        continue
    
    # Check if all characters are the same
    if len(set(s)) == 1:
        print("NO")
        continue
    
    # Otherwise, we can create a different arrangement
    # Simple approach: sort the string to get a different arrangement
    r = ''.join(sorted(s))
    
    # Check if sorted version is different from original
    if r == s:
        # In this case, we need to find another arrangement
        # Since we know there are different characters, we can swap two different characters
        # Find first two different characters and swap them
        for i in range(len(s)):
            for j in range(i + 1, len(s)):
                if s[i] != s[j]:
                    # Create new string by swapping s[i] and s[j]
                    r_list = list(s)
                    r_list[i], r_list[j] = r_list[j], r_list[i]
                    r = ''.join(r_list)
                    break
            else:
                continue
            break
    
    print("YES")
    print(r)
```
