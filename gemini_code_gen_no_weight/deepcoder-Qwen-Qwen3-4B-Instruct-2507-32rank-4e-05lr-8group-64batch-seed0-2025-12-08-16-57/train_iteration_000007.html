## Problem Understanding

1. Takahashi has N days of vacation
2. He has M assignments, where the i-th assignment takes A_i days to complete
3. He can only work on one assignment per day
4. He cannot hang out on days he's working on assignments
5. We need to find the maximum number of days he can hang out
6. If he can't finish all assignments within N days, return -1

## Key Insights

1. The total days needed to complete all assignments is the sum of all A_i days
2. If the total assignment days exceed N, then it's impossible to complete all assignments → return -1
3. If the total assignment days ≤ N, then the remaining days (N - sum of all A_i) are the days he can hang out

## Step-by-step Solution

1. Read N (vacation days) and M (number of assignments)
2. Read the array A of assignment durations
3. Calculate the total days needed for all assignments: sum(A)
4. Check if total days needed > N:
   - If yes, return -1 (impossible to complete)
5. If total days needed ≤ N, return (N - sum(A)) as the hangout days

## Verification with Sample

- N = 41, M = 2
- Assignments: 5 days, 6 days
- Total assignment days = 5 + 6 = 11
- Since 11 ≤ 41, he can complete all assignments
- Hangout days = 41 - 11 = 30 ✓

# Read input

    hangout_days = N - total_assignment_days
